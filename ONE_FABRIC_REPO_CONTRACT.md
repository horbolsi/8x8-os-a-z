# One-Fabric Repository Contract

Canonical root: `fabric://8x8/core`

## Repository role
Public A→Z product guide and capability map.

## Current upgrade focus
Keep documentation synchronized with evidence-backed public state; add versioned capability taxonomy, accessibility mapping, glossary, change ledger and explicit historical/future labels.

## Quality gates
- role, authority, privacy and lifecycle state are explicit;
- dependency/predecessor/successor relationships are maintained;
- tests/verification are reproducible and evidence-backed;
- security and secret boundaries are enforced;
- provenance and rollback are mandatory for promoted changes;
- benchmark claims include dated baseline and denominator;
- agents operate only under scoped grants and independent verification.

## Agent persona contract
Stable persona may include name, role, style, memory policy, languages, avatar/voice/body metadata and specialization. Persona continuity is permitted; unsupported claims of human biology, consciousness, emotions, legal identity or unrestricted authority are not.

## Scorecard
Documentation, test pass rate, CI/release health, security, provenance, freshness, performance, duplicate/superseded surface, rollback and agent-readiness.

## Continuous loop
`DISCOVER -> RECONCILE -> IMPLEMENT -> TEST -> VERIFY -> RECEIPT -> SCORE -> PROMOTE/ROLLBACK -> RESEARCH -> REPEAT`
